# Dreamina Seedance 2.0 API & Prompting Guide

## Overview
Dreamina Seedance 2.0 series (Seedance 2.0 and Seedance 2.0 Fast) models support multimodal input (images, videos, audios, and texts) for video generation, editing, and video extension. They can restore item details, timbres, effects, styles, camera movements with high accuracy, maintain consistent character features, and give users enterprise-grade control.

### Model IDs & Capabilities
- **Dreamina Seedance 2.0**: `dreamina-seedance-2-0-260128` (High fidelity, audio-video sync, motion control, supports 1080p)
- **Dreamina Seedance 2.0 Fast**: `dreamina-seedance-2-0-fast-260128` (Rapid generation, silent or audio-video, maximum 720p resolution)

## 1. Request Parameters & Constraints

The creation API endpoint is a `POST` request to:
`https://ark.ap-southeast.bytepluses.com/api/v3/contents/generations/tasks`

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `model` | string | Yes | ID of the model (e.g. `dreamina-seedance-2-0-260128`). |
| `content` | object[] | Yes | Array of text, image, video, and audio reference elements. |
| `ratio` | string | No | Aspect ratio: `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `21:9`, or `adaptive`. |
| `resolution` | string | No | Video resolution: `480p`, `720p`, `1080p` (1080p not supported by Fast). |
| `duration` | integer | No | Duration in seconds: `[4, 15]`. |
| `generate_audio` | boolean | No | `true` to generate synced audio. |
| `watermark` | boolean | No | `true` to include an "AI Generated" watermark. |

### Multimodal Content Allowances
- **Images**: 0–9 images
- **Videos**: 0–3 videos
- **Audio**: 0–3 audios
*Note: "Text + audio" and "audio-only" inputs are not supported without visuals.*

> [!CAUTION]
> **Human Faces Security**: Only face-containing outputs generated by ModelArk within the last 30 days are trusted as input assets. External real-person faces will be intercepted. To bypass, use Preset Digital Characters by passing `asset://<asset ID>` in the `image_url` or `video_url`.

## 2. Prompt Engineering Techniques

### General Principles
The logical foundation of generation is defining "who" is performing "what action", the spatial background/lighting, and sound effects for immersive sync.

Prompts must reference assets in the format **Asset Type + Number** (e.g., "Image 1", "Video 2"). The number is the sorting order of the asset among assets of the same type in the request body (1-indexed). 
*Do NOT reference assets by their Asset ID in the prompt text.*

### Rendering Text (Slogans, Subtitles, Speech Bubbles)
- **Slogans**: `[Text Content] + [Timing] + [Positioning] + [Entrance/Appearance Style], [Visual Attributes]`
- **Subtitles**: `Display subtitles at the bottom-center with the text. The subtitles must be perfectly synchronized with the audio rhythm.`
- **Speech Bubbles**: `[Character] says, "[Dialogue]." Speech bubbles appear around the character containing the spoken text.`

### Image Reference (Multi-perspective, Multi-image)
- **Subject Reference**: `Extract the [Subject] from [Image 1] to generate [Scene Description], maintaining consistent [Subject] features.`
- **Multi-Element**: `The scene is set in the restaurant from Image 4. The girl from Image 1, wearing the clothes from Image 2...`

### Video Reference (Motion, Camera, VFX)
- **Motion**: `Refer to the character movements from [Video 1] to create a fight scene...`
- **Camera Movement**: `Referring to the camera movement in [Video 1], create a concept video...`
- **VFX**: `Refer to the golden particle effects in [Video 1] so that when the character plays the flute...`

## 3. Video Editing & Extension

### Video Editing (Add, Remove, Modify)
- **Adding**: `At [Timestamp] of [Video 1], add [Element].`
- **Removing**: `Remove [Element] from [Video 1], keeping the rest unchanged.`
- **Modifying**: `Replace the cat in [Video 1] with the lion from [Image 1].`

### Video Extension
- **Extend Forward/Backward**: `Extend the opening segment of [Video 1]: [Description of extended content].`
- **Track Stitching (Max 3 clips)**: `[Video 1] + [transition description] + connect to [Video 2] + [transition description] + connect to [Video 3].`

## 4. Example Payloads

### Multimodal Video Generation
```json
{
    "model": "dreamina-seedance-2-0-260128",
    "content": [
        {
            "type": "text",
            "text": "Use the first-person POV framing from Video 1. First-person POV fruit tea ad; opening frame is Image 1, hand picks apple. Final frame freezes on Image 2. Background audio uses Audio 1."
        },
        {
            "type": "image_url",
            "image_url": { "url": "https://url.com/img1.jpg" },
            "role": "reference_image"
        },
        {
            "type": "image_url",
            "image_url": { "url": "https://url.com/img2.jpg" },
            "role": "reference_image"
        },
        {
            "type": "video_url",
            "video_url": { "url": "https://url.com/vid1.mp4" },
            "role": "reference_video"
        },
        {
            "type": "audio_url",
            "audio_url": { "url": "https://url.com/aud1.mp3" },
            "role": "reference_audio"
        }
    ],
    "generate_audio": true,
    "ratio": "16:9",
    "duration": 11
}
```

### Video Editing
```json
{
    "model": "dreamina-seedance-2-0-260128",
    "content": [
        {
            "type": "text",
            "text": "Replace the cat in [Video 1] with the lion from [Image 1]. The lion lies gently across the girl’s legs."
        },
        {
            "type": "image_url",
            "image_url": { "url": "https://url.com/lion.jpg" },
            "role": "reference_image"
        },
        {
            "type": "video_url",
            "video_url": { "url": "https://url.com/cat_video.mp4" },
            "role": "reference_video"
        }
    ],
    "duration": 5
}
```

### Digital Character Substitution
```json
{
    "model": "dreamina-seedance-2-0-260128",
    "content": [
        {
            "type": "text",
            "text": "Vertical HD close-up of a beauty blogger (Image 1). She holds a face cream jar (Image 2). Character speaks in real-time."
        },
        {
            "type": "image_url",
            "image_url": { "url": "asset://asset-20260401123823-6d4x2" },
            "role": "reference_image"
        },
        {
            "type": "image_url",
            "image_url": { "url": "https://url.com/product.jpg" },
            "role": "reference_image"
        }
    ]
}
```
